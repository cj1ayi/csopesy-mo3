## Instructions to Run

### Linux
1. Navigate to the SOURCE folder.
2. Compile: `g++ *.cpp -o csopesy_mo3 -I ../include`
3. Run: `./csopesy_mo3`

### Windows
1. Navigate to the SOURCE folder.
2. Compile: `g++ *.cpp -o csopesy_mo3.exe -I ../include`
3. Run: `csopesy_mo3.exe`

### Alternative (CMake)
1. `cmake -S . -B build`
2. `cmake --build build`
3. `./build/csopesy_mo3`
